## Archivio di Bilancio

La vecchia app (Bilancio, fino alla 0.45.0) non fa più parte del progetto ma si recupera:
- ramo `archivio/bilancio` e tag `archivio-bilancio-v0.45.0` su GitHub;
- il suo `README.md` e `CLAUDE.md` si leggono con `git show archivio/bilancio:README.md`.

Per consultarla senza toccare `main`: `git worktree add ../Bilancio-archivio archivio/bilancio`.
